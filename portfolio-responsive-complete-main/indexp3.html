About

The project focuses on creating an interactive dashboard for visualizing population demographics across various Indian states. This dashboard enables users to explore insights related to gender distribution, literacy rates, and population density. By leveraging AWS services and QuickSight, the solution allows for dynamic data filtering and analysis, providing users with a seamless experience to better understand population trends and demographics across different states.


Technologies Used: Python, AWS S3, AWS QuickSight
